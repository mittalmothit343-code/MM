========================================================================
AUDIO FOLDER CONFIGURATION - TWO SHIPS IN AN INFINITE OCEAN
========================================================================

You can drop your own MP3 audio files directly into this directory (assets/audio/)
to customize the background music for each scene of the story!

SUPPORTED FILE NAMES & SCENE TIMINGS:

1. 1_search.mp3         -> Plays while searching for ships (Scenes 1 - 2)
2. 2_contact1.mp3       -> Plays when 1st ship (Mohit) is found (Scene 3)
3. 3_contact2.mp3       -> Plays when 2nd ship (Sezal) is found (Scene 4)
4. 4_romantic_meet.mp3  -> Plays when both ships sail towards each other and meet (Scenes 5 - 7)
5. 5_ending.mp3         -> Plays during harbour keepsakes & ending gallery (Scenes 8 - 10)

ALTERNATIVE ALL-IN-ONE MUSIC FILE:
- music.mp3 or felitsa.mp3 -> Plays throughout the entire story if scene-specific files are not provided.

Note: You can also manage/upload multi-files directly from the web interface audio menu!
